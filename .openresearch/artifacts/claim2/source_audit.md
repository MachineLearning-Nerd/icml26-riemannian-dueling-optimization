# Source audit

Algorithm 2 and Theorem 3.10 (`#alg2`, `#S3.Thmtheorem10`) print an increasing
epsilon schedule. Appendix F requires a decreasing schedule. Source SHA-256:
`1b20e2af562744080126d140c55b72c92658e355d8b93086c0e2908f762fb323`.

The official registry claim concerns the intended RRDNGD complexity result,
not solely the typographical schedule. The adjudication therefore verifies the
Appendix-F-consistent theorem and reports the literal Algorithm 2 failure as a
separate source defect.
